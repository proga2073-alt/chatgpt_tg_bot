# Telegram AI Chat Bot

Telegram-бот на ChatGPT-совместимом API (`https://zenvy.su/v1`). Весь интерфейс — внутри бота (кнопки и команды), отдельного веб-приложения нет.
Платные модели за Telegram Stars, админ-панель, а модель умеет рисовать и править изображения, создавать и изменять файлы и (только для админов) выполнять команды cmd.

## Быстрый старт

```bash
pip install -r requirements.txt
python run.py          # при первом запуске спросит OPENAI_API_KEY, BOT_TOKEN и ADMIN_IDS и сохранит их в .env
```

`BOT_TOKEN` берётся у **@BotFather** (`/newbot`), свой Telegram ID для `ADMIN_IDS` — у **@userinfobot**.
Заново ввести ключи: `python run.py --reconfigure`. HTTPS, домен и туннели больше не нужны — бот работает через long polling.

Docker: `cp .env.example .env` (заполнить) → `docker compose up -d --build`. Данные (БД и файлы пользователей) лежат в томе `botdata`.

## Что умеет бот

| Возможность | Как пользоваться |
|---|---|
| Чат с памятью контекста | просто пишите; `/new` — новый диалог; под ответом «🔄 Заново», во время ответа «⏹ Стоп» |
| Диалоги | `/chats` — список, поиск, переименование, удаление, экспорт в `.txt` (`/export`) |
| Модель и настройки | `/model` (цены в ⭐), `/settings`: температура, длина ответа, системный промт; `/persona` — готовые роли |
| Изображения | попросите «нарисуй …» или пришлите картинку с подписью «измени …» |
| Файлы | пришлите документ с подписью-задачей — модель прочитает, изменит и вернёт файл; `/files` — ваши файлы |
| Баланс | `/balance`, `/buy` (Telegram Stars), `/promo КОД` |
| Статистика | `/stats` |
| Админ-панель | `/admin` (только `ADMIN_IDS`) |

### Изображения, файлы, команды: как это устроено

Модель получает инструменты (function calling): `generate_image`, `edit_image`, `write_file`, `read_file`, `list_files` и `run_command`. Она сама решает, когда их вызвать; результат отправляется в чат.

- **Нужна поддержка провайдера.** Для картинок — эндпоинты `/images/generations` и `/images/edits` и модель из `IMAGE_MODEL`; для инструментов — параметр `tools` в `/chat/completions`. Если провайдер что-то не принимает, бот сообщает об этом и продолжает работать как обычный чат (при отказе от `tools` — на 10 минут без них).
- **Изображения платные:** `IMAGE_COST_CREDITS` (по умолчанию 3 ⭐), админам бесплатно; при ошибке ⭐ возвращаются.
- **Файлы:** у каждого пользователя своя папка `data/workspace/<id>/` (до 60 файлов, имена очищаются от путей). Текстовые файлы до 20 КБ подставляются в запрос целиком, большие модель читает кусками.
- **Команды cmd — отдельное предупреждение.** По умолчанию выключены (`ENABLE_SHELL=false`). Если включить: доступны только `ADMIN_IDS`, **каждая команда выполняется только после нажатия «✅ Выполнить»** под её показанным текстом, с таймаутом (`SHELL_TIMEOUT`) и ограничением вывода; вывод показывается в чате и пишется в лог. Но это **не песочница**: команда исполняется с правами процесса бота и видит весь компьютер/сервер, а не только рабочую папку. Читайте команду перед подтверждением, не запускайте бота от администратора и не включайте на машине с чувствительными данными. Обычным пользователям инструмент недоступен, даже если модель попытается его вызвать.

## Платные модели (Telegram Stars)

Бесплатные модели — `FREE_MODELS` (по умолчанию `gpt-5.6-terra`), остальные платные: за каждое сообщение списывается **множитель модели × `MESSAGE_BASE_CREDITS`** кредитов (10 кредитов = 1 ⭐). Множители из таблицы zenvy.su заложены в `config.py`; в админ-панели их можно менять на лету, скрывать модели и переключать «бесплатная/платная».

- Пополнение: `/buy`, пакеты `STAR_PACKS`; оплата валютой `XTR`, платёжный токен не нужен. Платежи пишутся в таблицу `payments`, повторная доставка не зачислит ⭐ дважды.
- Если модель не вернула ни текста, ни файлов (ошибка, «Стоп» до первого токена) — списанные ⭐ возвращаются.
- Команда `/paysupport` обязательна для платёжных ботов; контакт — `SUPPORT_CONTACT`.
- Возвраты — в админ-панели («Платежи» → «Вернуть»): вызывается `refundStarPayment`, зачисленные кредиты списываются (не ниже нуля).
- **Сверьте цены со своими расходами на zenvy.su:** курс ⭐ к вашей оплате у каждого свой. Агентные запросы (инструменты) могут делать до `MAX_TOOL_STEPS` обращений к модели за одно списание.

## Админ-панель (`/admin`)

- **Статистика:** пользователи, активные за 24 ч, сообщения, платежи, остатки на балансах.
- **Пользователи:** поиск по ID или @username, начисление и списание ⭐ (пользователю приходит уведомление), блокировка.
- **Модели и цены:** скрыть модель, сделать бесплатной/платной, задать множитель, сбросить к `.env`.
- **Промокоды:** создание (`КОД ЗВЁЗДЫ [ЛИМИТ]`), удаление; пользователь вводит `/promo КОД`, один раз на код.
- **Платежи:** последние 10, возврат ⭐.
- **Рассылка:** любое сообщение (текст, фото, файл) всем незаблокированным пользователям, с предпросмотром и подтверждением.

## Структура

```
main.py, run.py        # запуск; run.py — с первичной настройкой
config.py              # настройки из .env
bot/                   # хэндлеры (handlers/), инструменты модели (tools.py), клавиатуры, middleware
services/              # чат и лимиты, цены, рабочая папка, Markdown → Telegram-HTML
llm/client.py          # AsyncOpenAI: стрим с function calling, изображения, ретраи
db/                    # модели и запросы (SQLite / PostgreSQL)
```

## Решения по умолчанию

- Один процесс: лимиты и флаг «идёт генерация» хранятся в памяти (для нескольких инстансов вынесите в Redis); состояние диалогов-вопросов (FSM) тоже в памяти и сбрасывается при перезапуске.
- Контекст: последние 20 сообщений, не более ~12 000 символов. В историю попадает итоговый текст ответа и список созданных файлов, но не промежуточные вызовы инструментов.
- Ретраи при таймауте, 429 и 5xx — до 3 раз с паузами 1/2/4 с, только пока ничего не получено.
- Длинные ответы режутся на сообщения до 4096 символов после конвертации в HTML; блоки кода копируются нажатием.
- Схема БД создаётся автоматически, недостающие колонки добавляются при старте (для миграций в продакшене подключите Alembic). Время — UTC.
- Изображения принимаются как файлы для редактирования; «зрения» (описания картинок моделью) нет.

## Частые проблемы

- `Telegram не принял BOT_TOKEN` — токен неверен или отозван: `python run.py --reconfigure`.
- `404 model_not_found` — модели нет у провайдера: выберите другую в `/model` или поправьте `OPENAI_MODEL`.
- Картинки не рисуются — провайдер не поддерживает `/images/*` или `IMAGE_MODEL` недоступна: бот так и скажет.
- Инструменты не вызываются — провайдер/модель не поддерживает `tools`; в логе будет предупреждение, чат продолжит работать.
- `/admin` не отвечает — ваш ID не указан в `ADMIN_IDS`.
